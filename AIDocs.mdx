# AI-Friendly Documentation Guide for stenajs-webui

This guide is designed to help AI systems understand and work with the stenajs-webui packages. Each section contains links to detailed documentation that can be referenced or copied to other projects.

## Package Overview

stenajs-webui is a React component framework and design system with the following main packages:

### Core Packages

- `@stenajs-webui/core` - Foundation components and utilities
- `@stenajs-webui/theme` - Theming system and design tokens
- `@stenajs-webui/elements` - Basic UI elements and components

### Form and Input Packages

- `@stenajs-webui/forms` - Form components and form handling
- `@stenajs-webui/input-mask` - Input masking functionality
- `@stenajs-webui/select` - Select and dropdown components

### Layout and Structure Packages

- `@stenajs-webui/panels` - Panel and layout components
- `@stenajs-webui/modal` - Modal and dialog components
- `@stenajs-webui/grid` - Grid system and table components
- `@stenajs-webui/grid-export` - Grid data export utilities

### UI Enhancement Packages

- `@stenajs-webui/calendar` - Calendar and date-related components
- `@stenajs-webui/tooltip` - Tooltip components
- `@stenajs-webui/filter` - Filter components and utilities

### State Management

- `@stenajs-webui/redux` - Redux integration and utilities

## Common Patterns and Relationships

### Component Dependencies

- Most packages depend on `@stenajs-webui/core`
- UI components typically use `@stenajs-webui/theme` for styling
- Form components often integrate with `@stenajs-webui/elements` for basic inputs

### State Management

- Redux integration available through `@stenajs-webui/redux`
- Local state management patterns in individual components
- Context providers for feature-specific state (e.g., filters, modals)

### Styling System

- CSS modules for component styling
- Theme variables for consistent design
- Customization through CSS variables
- Support for styled-system props

### Common Props Patterns

- Most components accept standard HTML attributes
- Consistent use of `className` for custom styling
- Common prop patterns for size, variant, and state
- Standardized event handler props

## Integration Patterns

### Basic Setup

```typescript
import { ThemeProvider } from "@stenajs-webui/theme";
import { CoreComponent } from "@stenajs-webui/core";

const App = () => (
  <ThemeProvider>
    <CoreComponent />
  </ThemeProvider>
);
```

### Form Integration

```typescript
import { Form } from "@stenajs-webui/forms";
import { TextInput } from "@stenajs-webui/elements";

const FormComponent = () => (
  <Form onSubmit={handleSubmit}>
    <TextInput name="field" />
  </Form>
);
```

### Grid with Filters

```typescript
import { StandardTable } from "@stenajs-webui/grid";
import { SearchFilterProvider, SearchFilterDrawer } from "@stenajs-webui/filter";

const TableWithFilters = () => (
  <SearchFilterProvider>
    <SearchFilterDrawer>
      {/* Filter components */}
    </SearchFilterDrawer>
    <StandardTable config={tableConfig} items={items} />
  </SearchFilterProvider>
);
```

## Best Practices for AI Integration

1. **Component Selection**

   - Use the most specific component for the task
   - Consider accessibility requirements
   - Check for mobile responsiveness needs

2. **State Management**

   - Use Redux for complex state
   - Use local state for simple components
   - Consider context for feature-specific state

3. **Styling Approach**

   - Prefer CSS variables for customization
   - Use theme tokens for consistency
   - Apply responsive styles using styled-system

4. **Performance Considerations**

   - Lazy load large components
   - Use proper key props in lists
   - Consider memoization for complex components

5. **Error Handling**
   - Implement proper form validation
   - Handle loading and error states
   - Provide user feedback for actions

## Common Use Cases

1. **Form Handling**

   ```typescript
   import { Form, TextInput, SubmitButton } from "@stenajs-webui/forms";

   const FormExample = () => (
     <Form onSubmit={handleSubmit}>
       <TextInput name="username" label="Username" />
       <SubmitButton label="Submit" />
     </Form>
   );
   ```

2. **Data Display**

   ```typescript
   import { StandardTable } from "@stenajs-webui/grid";
   import { StandardTableExcelExportButton } from "@stenajs-webui/grid-export";

   const TableExample = () => (
     <>
       <StandardTableExcelExportButton config={config} items={items} />
       <StandardTable config={config} items={items} />
     </>
   );
   ```

3. **Modal Dialogs**

   ```typescript
   import { Modal } from "@stenajs-webui/modal";

   const ModalExample = () => (
     <Modal isOpen={isOpen} onRequestClose={handleClose}>
       <ModalContent />
     </Modal>
   );
   ```

## Troubleshooting Guide

1. **Styling Issues**

   - Check theme provider setup
   - Verify CSS variable definitions
   - Check for CSS module conflicts

2. **State Management**

   - Verify Redux store configuration
   - Check context provider hierarchy
   - Validate state updates

3. **Component Integration**

   - Check required peer dependencies
   - Verify component prop types
   - Review component documentation

4. **Performance Issues**
   - Check for unnecessary rerenders
   - Verify proper data structure usage
   - Review component lifecycle

## Version Compatibility

- TypeScript 4.0+
- Modern browser support
- CSS Variables support required
